四、常用 Kali 指令

4.1 系统管理

命令 说明
uname -a 查看系统内核信息
cat /etc/os-release 查看系统发行版信息
hostnamectl 查看和设置主机名
whoami 查看当前登录用户
id 查看当前用户 ID 和组信息
uptime 查看系统运行时间
date 查看系统日期时间
cal 显示日历
shutdown -h now 立即关机
shutdown -r now 立即重启
reboot 重启系统
exit 退出当前终端

4.2 网络相关

命令 说明
ifconfig 查看网络接口信息
ip addr 查看 IP 地址（新版）
ip route 查看路由表
ping <IP/域名> 测试网络连通性
traceroute <IP/域名> 追踪路由路径
netstat -tuln 查看端口监听状态
ss -tuln 查看端口监听状态（新版）
nslookup <域名> DNS 查询
dig <域名> DNS 详细查询
curl <URL> 发送 HTTP 请求
wget <URL> 下载文件
nmap <IP> 端口扫描
arp -a 查看 ARP 缓存表
iwconfig 查看无线网络信息

4.3 文件操作

命令 说明
ls -la 列出文件详细信息
cd <目录> 切换目录
pwd 显示当前路径
mkdir <目录名> 创建目录
rmdir <目录名> 删除空目录
rm -rf <文件/目录> 强制删除文件或目录
cp <源> <目标> 复制文件或目录
mv <源> <目标> 移动或重命名文件
touch <文件名> 创建空文件或更新时间戳
cat <文件名> 查看文件内容
less <文件名> 分页查看文件内容
head -n 10 <文件名> 查看文件前 10 行
tail -n 10 <文件名> 查看文件后 10 行
tail -f <文件名> 实时查看文件追加内容
find <路径> -name <文件名> 查找文件
grep <模式> <文件> 搜索文件内容
tar -czvf <归档名.tar.gz> <目录> 压缩为 tar.gz
tar -xzvf <归档名.tar.gz> 解压 tar.gz
zip -r <归档名.zip> <目录> 压缩为 zip
unzip <归档名.zip> 解压 zip
chmod 755 <文件> 修改文件权限
chown <用户>:<组> <文件> 修改文件所有者

4.4 权限管理

命令 说明
sudo <命令> 以 root 权限执行命令
su - 切换到 root 用户
su <用户名> 切换到指定用户
passwd 修改当前用户密码
passwd <用户名> 修改指定用户密码
useradd <用户名> 创建新用户
userdel <用户名> 删除用户
usermod -aG <组名> <用户名> 将用户添加到组
groupadd <组名> 创建新组
chmod u+x <文件> 给文件所有者添加执行权限
chmod g+w <文件> 给文件所属组添加写权限
chmod o+r <文件> 给其他用户添加读权限
chmod -R 777 <目录> 递归设置目录权限（谨慎使用）

4.5 进程管理

命令 说明
ps aux 查看所有进程
ps -ef 查看进程详细信息
top 实时查看进程状态
htop 增强版进程查看器
kill <PID> 终止指定 PID 的进程
kill -9 <PID> 强制终止进程
killall <进程名> 终止所有同名进程
pkill <进程名> 按名称终止进程
nohup <命令> & 后台运行命令
jobs 查看后台任务
fg %<编号> 将后台任务调到前台
bg %<编号> 将前台任务调到后台
systemctl start <服务名> 启动服务
systemctl stop <服务名> 停止服务
systemctl restart <服务名> 重启服务
systemctl status <服务名> 查看服务状态
systemctl enable <服务名> 设置服务开机自启

4.6 软件包管理

命令 说明
apt update 更新软件源列表
apt upgrade 升级所有软件包
apt full-upgrade 完整升级（含内核）
apt install <包名> 安装软件包
apt remove <包名> 卸载软件包
apt purge <包名> 彻底卸载（含配置文件）
apt autoremove 自动卸载不需要的依赖
apt search <关键词> 搜索软件包
apt show <包名> 查看软件包信息
apt list --installed 列出已安装的软件包
dpkg -i <包名.deb> 安装本地 deb 包
dpkg -r <包名> 卸载 deb 包
dpkg -l 列出所有已安装的 deb 包
snap install <包名> 安装 snap 包
flatpak install <包名> 安装 flatpak 包

4.7 信息收集

命令 说明
nmap -sV <IP> 扫描目标端口和服务版本
nmap -sS <IP> SYN 半开扫描
nmap -A <IP> 全面扫描（OS + 版本 + 脚本）
nmap -p- <IP> 扫描所有端口（1-65535）
nmap -sn <网段> Ping 扫描（发现存活主机）
nmap --script=<脚本名> <IP> 使用 NSE 脚本扫描
netdiscover -r <网段> 网络发现（ARP 扫描）
masscan <网段> -p<端口> 大规模端口扫描
dnsrecon -d <域名> DNS 枚举
dnsenum <域名> DNS 信息收集
theHarvester -d <域名> 收集邮箱、子域名等信息
whois <域名> WHOIS 查询
whatweb <URL> 识别网站技术栈
wappalyzer 浏览器扩展，识别网站技术
sublist3r -d <域名> 子域名枚举
dirb <URL> 目录扫描
gobuster dir -u <URL> -w <字典> 目录/文件爆破
nikto -h <URL> Web 服务器漏洞扫描

4.8 密码破解

命令 说明
john --wordlist=<字典> <哈希文件> John the Ripper 密码破解
hashcat -m <模式> -a 0 <哈希文件> <字典> Hashcat GPU 加速破解
hydra -l <用户名> -P <字典> <协议>://<IP> 在线密码爆破
hydra -L <用户字典> -P <密码字典> ssh://<IP> SSH 密码爆破
crunch <最小长度> <最大长度> <字符集> 生成密码字典
cewl <URL> 从网站爬取关键词生成字典
fcrackzip -D -p <字典> <加密zip> ZIP 密码破解
pdfcrack -f <PDF文件> -w <字典> PDF 密码破解
rar2john <RAR文件> 提取 RAR 哈希（用于 john）
ssh2john <私钥文件> 提取 SSH 密钥哈希

4.9 无线网络

命令 说明
iwconfig 查看无线网卡信息
airmon-ng 查看无线网卡状态
airmon-ng start <接口名> 开启网卡监听模式
airmon-ng stop <接口名> 关闭网卡监听模式
airodump-ng <接口名> 扫描无线网络
airodump-ng -c <信道> --bssid <MAC> -w <输出文件> <接口> 抓取指定 AP 数据包
aireplay-ng -0 <数量> -a <AP MAC> -c <客户端 MAC> <接口> Deauth 攻击
aircrack-ng -w <字典> <抓包文件> 破解 WPA/WPA2 密码
reaver -i <接口> -b <BSSID> -vv WPS PIN 破解
wash -i <接口> 扫描支持 WPS 的 AP
mdk4 <接口> d -b <BSSID> 洪水攻击（压力测试）
kismet 无线网络检测工具
wifite 自动化无线审计工具

4.10 漏洞分析

命令 说明
searchsploit <关键词> 搜索 Exploit-DB 漏洞库
searchsploit -m <编号> 复制漏洞利用代码到当前目录
msfconsole 启动 Metasploit 框架
msfvenom -p <payload> LHOST=<IP> LPORT=<端口> -f <格式> 生成 payload
sqlmap -u <URL> SQL 注入检测与利用
sqlmap -u <URL> --dbs 枚举数据库
sqlmap -u <URL> -D <数据库> --tables 枚举数据表
sqlmap -u <URL> --os-shell 获取系统 shell
burpsuite 启动 Burp Suite（需 Java）
zap 启动 OWASP ZAP
wpscan --url <URL> WordPress 漏洞扫描
joomscan -u <URL> Joomla 漏洞扫描
droopescan scan drupal -u <URL> Drupal 漏洞扫描
openvas-start 启动 OpenVAS 漏洞扫描器
lynis audit system 系统安全审计
