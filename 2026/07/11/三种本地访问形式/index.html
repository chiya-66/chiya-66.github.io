三种本地访问形式

一、 核心概念与可访问场景

+—————–+——————————————————————————————-+————————————————-+
| 地址形式 | 本质定义 | 可访问的前提条件 |
+=================+===========================================================================================+=================================================+
| localhost | 是一个域名，默认映射到回环地址 127.0.0.1（IPv4）和 ::1（IPv6），由本地 hosts 文件配置 | 1. 本地 hosts 文件未被篡改（默认已映射） |
| | | |
| | | 2. 服务监听了回环地址或所有地址（0.0.0.0） |
+—————–+——————————————————————————————-+————————————————-+
| 127.0.0.1 | IPv4 本地回环地址，属于回环网段 127.0.0.0/8 的代表地址 | 1. |
| | | 服务监听了回环地址 127.0.0.1 或所有地址 0.0.0.0 |
| | | |
| | | 2. 无需网卡、无需联网，仅在本机内部通信 |
+—————–+——————————————————————————————-+————————————————-+
| 192.168.xxx.xxx | 属于 私有 IPv4 地址（局域网地址），是本机在局域网中的唯一标识 | 1. 本机已连接局域网（有线 / |
| | | 无线），并获取了该私有 IP |
| | | |
| | | 2. 服务监听了该私有 IP 或所有地址 0.0.0.0 |
| | | |
| | | 3. 防火墙允许该端口的局域网访问 |
+—————–+——————————————————————————————-+————————————————-+

  1. 核心区别

1.访问范围不同

**localhost / 127.0.0.1：仅限本机内部访问。**数据不会经过物理网卡，完全在本机的
TCP/IP 协议栈内循环，即使断开网络、禁用网卡，也能正常访问。

例如：本机启动的 Web
服务，用 localhost:8080 或 127.0.0.1:8080 只能在本机打开，同一局域网的其他设备无法访问。

**192.168.xxx.xxx：支持局域网内跨设备访问。**数据会经过物理网卡，需要局域网路由转发。同一网段的其他设备（手机、电脑）可以通过 192.168.xxx.xxx:端口 访问本机服务。

2.解析机制不同

**localhost：属于域名解析，优先级高于
DNS。**系统会先读取 hosts 文件（Windows
路径：C:\Windows\System32\drivers\etc\hosts；Linux/macOS
路径：/etc/hosts），如果 hosts 中被修改为其他
IP（比如 192.168.1.100），则 localhost 会指向修改后的地址。

127.0.0.1 / 192.168.xxx.xxx：是直接的 IP
地址，无需解析，直接与对应地址的服务建立连接。

3.使用场景不同

localhost / 127.0.0.1：适合本机调试。比如开发阶段测试 Web
服务、数据库服务，避免局域网其他设备干扰，安全性更高。

**192.168.xxx.xxx：适合局域网内协同测试。**比如开发的网页需要在手机上预览，或团队成员在同一局域网访问你的测试服务。
