实验：内网凭证获取

1.概念和原理

1.1 前置知识

域环境中的设备：dc，员工的电脑，web server，sqlserver，exchangeserver

注： exchangeserver是一种邮件服务器，有一个web 界面，在浏览器中登录

而凭证获取就是通过已经拿到权限的服务器，进一步获取到这个服务器中的深层信息，主要是获取域管理员的一个凭证

1.1 凭证类型

凭证 位置 / 形态 说明
明文密码 内存、配置文件、历史记录 最高价值，可直接复用
NTLM Hash SAM、NTDS.dit、LSASS 可用于 Pass-the-Hash
Kerberos Ticket 内存、磁盘 TGT/TGS，可用于票据传递
LM Hash SAM 老系统遗留，可被轻易破解
SSH Key ~/.ssh/ 免密登录凭证
域缓存凭证 (DCC) 注册表 HKLM\SECURITY\Cache 域账号离线缓存，可离线爆破
