实验：内网隧道搭建

内网一层隧道搭建

1. 概念与原理

1.1 什么是”一层隧道”

在攻防场景中，攻击者通常位于外网，而目标的核心资产位于内网。攻击者无法直接访问内网，但往往能通过 Web 漏洞、弱口令、钓鱼等方式先拿下一台边界服务器（Web 服务器、DMZ 主机、跳板机等）。这台边界主机同时连通外网与内网，因此可作为”跳板”。

“一层隧道” 即指：利用边界主机作为中转，在攻击机与内网之间建立一条通信隧道，使攻击机能够通过边界主机访问原本不可达的内网资源。这是内网渗透的第一步，也是最基础、最关键的一层。

1.2 核心概念

概念 说明
正向连接 (Forward) 攻击机主动连接目标（目标需能直接被攻击机访问）
反向连接 (Reverse) 目标主动连接攻击机（目标可出网、攻击机有公网 IP，绕过防火墙常用）
端口转发 将某端口的流量转发到另一主机/端口
SOCKS 代理 通用代理协议，可将任意 TCP 流量经代理转发
多级/多层隧道 在一层隧道基础上继续深入，构建第二、三层隧道

1.3 隧道方向选择

  • 边界主机 可以主动出网（能连公网）→ 优先用反向连接（frp、chisel、ew rcsocks）。
  • 边界主机 只能被攻击机访问，不能主动出网 → 用正向连接（端口转发、正向代理）。
  • 边界主机 仅开放 80/443 等 Web 端口、网络限制严格 → 用应用层隧道（HTTP/DNS/ICMP）。本次实验目标
